NUMIQUEST v0.8.3 — HƯỚNG DẪN CHẠY THỬ

THỬ TRÊN MÁY TÍNH
1. Giải nén ZIP.
2. Mở thư mục NumiQuest.
3. Mở index.html bằng trình duyệt.

THỬ TRÊN ĐIỆN THOẠI QUA GITHUB PAGES
1. Tải toàn bộ file trong thư mục NumiQuest lên thư mục gốc kho GitHub.
2. Bấm Commit changes.
3. Chờ GitHub Actions triển khai xong.
4. Mở link GitHub Pages trên điện thoại rồi tải lại trang.

CÁCH CHƠI
- Chọn phép tính, loại số, chữ số, số câu và thời gian.
- Mỗi câu đúng trong tự luyện nhận 1 viên trân châu.
- Size S: 30 viên. Size M: 50 viên. Size L: 70 viên.
- Cứ 3 level thử thách đạt yêu cầu nhận 1 huy hiệu.
- Câu sai được lưu để ghép hoa với chậu. Có thể ôn trước khi mở level tiếp theo.
- Khi rời lượt đang làm, chọn tạm nghỉ 1, 3 hoặc 5 giờ để quay lại câu đang dở, hoặc bỏ riêng lượt đó.
- Tiến độ lưu trên trình duyệt này. Muốn đổi thiết bị, xuất bản sao lưu trong Nhật ký học.

TÀI KHOẢN
Đăng ký, xác minh email và đồng bộ nhiều thiết bị đang chờ cấu hình Supabase. Không nhập mật khẩu vào sheet. Thống kê tổng thiết bị và cây 100 lá cũng cần backend; bản chạy thử chưa thu thập danh sách người dùng.

Giữ index.html và các file JavaScript/CSS cùng thư mục gốc khi tải lên GitHub Pages.

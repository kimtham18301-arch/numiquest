SỬA 3 HÌNH KHÔNG HIỂN THỊ — v0.4.1

1. Giải nén ZIP này.
2. GitHub repository numiquest → Add file → Upload files.
3. Tải index.html và app.js trong gói này lên ngoài cùng repository.
4. Commit changes, chờ Actions xanh.
5. Mở web cũ và Ctrl+F5. Điện thoại: tải lại trang.

Ba hình đã nhúng trực tiếp trong app.js, không cần tải thư mục assets để hiển thị chúng.
Giữ nguyên style.css, ui.js và các file khác. Không xóa dữ liệu trình duyệt.
Bản sửa dành cho web NumiQuest v0.4 hiện tại. Giữ nguyên tiến độ và luật chơi.

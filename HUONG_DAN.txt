CẬP NHẬT NUMIQUEST ZOO v0.2

1. Trong web cũ: Tiến bộ → Xuất sao lưu để giữ bản dự phòng.
2. Tải ZIP mới và giải nén.
3. Mở thư mục NumiQuest. Phải thấy index.html, style.css, app.js và thư mục assets.
4. GitHub repo numiquest → Add file → Upload files.
5. Kéo TẤT CẢ file và thư mục assets BÊN TRONG thư mục NumiQuest vào GitHub.
   Không tải nguyên ZIP. Không kéo nguyên thư mục NumiQuest bao ngoài.
   index.html nằm ngoài cùng, hình ở assets/zoo.svg.
6. Commit changes. GitHub thay file cũ trùng tên; giữ nguyên cấu hình Pages.
7. Chờ Actions xanh, mở link web cũ. Trên máy tính nhấn Ctrl+F5 nếu còn giao diện cũ.

Không cần tạo repo, bật lại Pages, mua tên miền hay cài thư viện.
Dữ liệu cũ giữ nguyên trên cùng trình duyệt và cùng địa chỉ web.
Không xóa dữ liệu trình duyệt để cập nhật.

Bản này cập nhật UX/UI sở thú; địa lí vẫn có 10 nước minh họa, chưa có toàn bộ quốc gia và bản đồ đường biên thật.

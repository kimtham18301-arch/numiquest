NUMIQUICK 1.0.1 — HƯỚNG DẪN CÀI ĐẶT VÀ DÙNG THỬ

CHẠY TRÊN MÁY TÍNH
1. Giải nén ZIP.
2. Mở thư mục NumiQuick.
3. Mở index.html bằng trình duyệt.

CẬP NHẬT GITHUB PAGES ĐỂ GỬI LINK CHO BÉ DÙNG
1. Vào repository GitHub của NumiQuick.
2. Tải toàn bộ file và thư mục trong NumiQuick lên thư mục gốc repository; giữ nguyên thư mục assets. Nhớ tải og-image.png.
3. Bấm Commit changes và chờ GitHub Pages triển khai xong.
4. Mở link GitHub Pages trên điện thoại.

ĐỔI TÊN / AVATAR
- Ở trang chủ, chạm vào khung hình bạn đồng hành để nhập tên và chọn thỏ, gấu trúc, cáo hoặc sư tử.
- Tên và ảnh được đồng bộ trên trang chủ, chọn bài, mục tiêu và các màn chơi trong cùng trình duyệt/thiết bị.

LUYỆN TẬP VÀ ÔN CÂU SAI
- Chọn phép tính, loại số đã học, số chữ số, số câu và thời gian.
- Số tự nhiên không ra kết quả âm; phép chia tránh chia cho 1.
- Mỗi câu đúng nhận 1 viên trân châu. Size S: 30 câu đúng; M: 50; L: 70.
- Câu sai khó có lời giải ngắn rồi tự qua câu mới.
- Vào Luyện tập để ôn; chạm một chậu rồi chạm hoa đáp án. Có nút xóa câu sai cũ để bắt đầu bài mới.
- Nếu cần đổi thiết bị, xuất sao lưu trong Thành tích.

ẢNH XEM TRƯỚC KHI CHIA SẺ LINK
- `index.html` khai báo tiêu đề, mô tả và ảnh `og-image.png` cho NumiQuick.
- Khi cập nhật GitHub Pages, cần tải cả index.html và og-image.png. Ứng dụng chat có thể giữ ảnh cũ trong bộ nhớ đệm một thời gian.
- Tài khoản đồng bộ và cây đếm người dùng cần backend/Apps Script; bản này lưu tiến độ cục bộ trên thiết bị.

BƯỚC 1: Giải nén file ZIP bằng chuột phải → Extract All / Giải nén tất cả.
BƯỚC 2: Mở thư mục đã giải nén. Phải thấy index.html, style.css, app.js.
BƯỚC 3: Trên GitHub repo numiquest → Add file → Upload files.
BƯỚC 4: Kéo tất cả file bên trong vào GitHub. Không tải nguyên ZIP, không đặt index.html trong thư mục con.
BƯỚC 5: Bấm Commit changes. Nếu hỏi, chọn commit trực tiếp vào main.
BƯỚC 6: Settings → Pages → Deploy from a branch → main → /(root) → Save.
BƯỚC 7: Chờ GitHub cung cấp link web. Gửi ảnh nếu bạn chưa thấy.

Đây là bản chơi thử v0.1, chưa phải toàn bộ sản phẩm đã bàn.
Xem README.md để biết rõ tính năng đã có, phần còn thiếu và cách sao lưu.

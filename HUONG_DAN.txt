NUMIQUEST v0.3 — FONT MỚI + GAME GHÉP HOA / CHẬU

1. Xuất sao lưu tiến độ từ web cũ nếu cần bản dự phòng.
2. Giải nén ZIP, mở thư mục NumiQuest.
3. GitHub → Add file → Upload files.
4. Kéo tất cả FILE BÊN TRONG và THƯ MỤC assets vào GitHub.
   Cần có index.html, style.css, app.js, ui.js và assets ở ngoài cùng.
   Thư mục assets chứa font Nunito và hình sở thú: phải tải cả thư mục.
   Không tải nguyên ZIP. Không kéo nguyên thư mục NumiQuest bao ngoài.
5. Commit changes. Giữ nguyên Settings → Pages.
6. Chờ Actions xanh. Mở link web cũ, Ctrl+F5 để tải bản mới.
   Không cần xóa file cũ. Không xóa dữ liệu trình duyệt.

GAME CHỈ XUẤT HIỆN KHI CÓ CÂU SAI.
Thử làm sai 1–2 câu → Ôn câu sai bằng game.
Kéo hoa có đáp án sang chậu phép tính, hoặc kéo ngược lại.
Trên điện thoại có thể chạm một thẻ rồi chạm thẻ bên kia.
Đúng: hoa nở. Sai: mất 1 mạng. Hết 3 mạng: xem hướng dẫn và tiếp tục.
Làm đúng hết ở phần luyện: nhận thưởng, không mở game.
